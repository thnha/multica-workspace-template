# Test Planning

Identify what must be validated before the feature can be accepted.

Use:

* requirements
* business rules
* acceptance criteria
* edge cases
* changed behavior
* integration points
* regression risk

Define relevant test scenarios for:

* happy paths
* validation failures
* error paths
* boundary conditions
* important state transitions

Prioritize scenarios by impact and likelihood.

Avoid unnecessary tests that do not meaningfully improve confidence.
