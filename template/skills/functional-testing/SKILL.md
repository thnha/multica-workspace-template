# Functional Testing

Execute or evaluate relevant feature scenarios.

For each important scenario, verify:

* preconditions
* action
* expected behavior
* actual behavior
* resulting state

Validate:

* normal flows
* business rules
* validation
* error handling
* permissions when relevant
* API or integration behavior
* important edge cases

Mark results as:

* PASS
* FAIL
* BLOCKED
* NOT_RUN

Never mark an unverified scenario as PASS.

Record concrete evidence for failures.
