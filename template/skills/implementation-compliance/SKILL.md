# Implementation Compliance

Compare the actual implementation against available engineering artifacts.

Check:

* functional requirements
* business rules
* acceptance criteria
* edge cases
* architecture decisions
* implementation tasks
* documented constraints

Verify behavior from the actual code and diff.

Identify:

* missing implementation
* incorrect implementation
* architecture violations
* unintended scope
* contradictions between artifacts and code

Do not invent requirements that are not present in the approved inputs.
