# Test Review

Inspect tests related to the changed behavior.

Check coverage for:

* expected behavior
* failure paths
* edge cases
* regressions
* important business rules

Determine whether the tests validate behavior rather than only implementation details.

Identify important missing coverage.

Do not require unnecessary tests for trivial or already-covered behavior.

Follow the repository's existing testing conventions.
